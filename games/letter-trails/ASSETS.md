# Letter Trails asset manifest

Letter Trails is self-contained and makes no runtime requests to third-party media services.

## In-game companions

The first release renders Unicode emoji inside an original, consistent sticker-token treatment defined in `style.css`. The emoji characters are text glyphs supplied by the visitor's operating system; no emoji image files are copied or redistributed by this repository. Every companion has a character-focused fallback label in `data.js`.

## Letterforms and interface

All SVG centerline geometry, interface code, colors, effects, and layouts in this directory were created specifically for Letter Trails. The worksheet screenshots supplied during design were used only as conceptual references for numbered stroke order and draggable companions; no artwork was copied from them.
